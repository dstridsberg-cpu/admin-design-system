Admin Design System

Everything you need to build a new demo consistently and quickly.

This showcase is the reference for all visual components used across demos. Every component is implemented as a Jinja2 macro — import what you need, call it with parameters, and the HTML renders correctly styled without writing any CSS. All visual decisions live in tokens.css, which is the only file the designer updates. Pull the latest version of that file and your demo automatically reflects the current design.

Starting a new demo
Link two files
Add tokens.css and components.css to your HTML head. That's the full styling setup — no build step, no npm, no preprocessor required.
Using components
Jinja2 macros
Each component lives in -showcase/templates/components/ as a .html macro file. Import the macro at the top of your template, then call it anywhere with the parameters shown in this showcase.
Keeping up with design
Pull tokens.css
The designer updates tokens.css only. Pull the latest version into your demo and all colors, spacing, typography, and radii update in one go — no component changes needed.

Surfaces

--surface-*

Background layers that create depth in the UI. Stack from darkest (outermost) to lightest (innermost). Never use grey primitives directly — always reference a surface token.

--surface-bg
Page/viewport background. The outermost layer.
--surface-primary
Cards, panels, modals, dropdowns.
--surface-secondary
Hover states, nested surfaces, table row hover.
--surface-tertiary
Active/selected states, code blocks, inset areas.
--surface-header
Top navigation bar. Translucent with backdrop blur.
--surface-sidebar
Left sidebar. Translucent with backdrop blur.

Text

--text-*

Text color roles. Always use these — never reference grey primitives directly in text. The three main roles (primary, secondary, tertiary) form a hierarchy of emphasis.

--text-primary
Headings, names, key data. Highest emphasis.
--text-secondary
Body text, descriptions. Medium emphasis.
--text-tertiary
Labels, timestamps, placeholders. Lowest emphasis.
--text-inverse
Text on dark or filled backgrounds (e.g. filled buttons).
--text-link
Clickable inline text links.
--text-on-dark
Text inside the AI agent dark panel and code blocks.

Borders

--border-*

Border and divider colors at three levels of visibility. Use subtle for floating elements, default for standard structure, strong for prominent dividers.

--border-subtle
Very faint borders on floating cards and overlays.
--border-default
Standard borders on inputs, cards, and containers.
--border-strong
Prominent dividers, header bottom edge, section breaks.

Interactive

--accent-*

The primary interactive color. Used for focus rings, active nav items, primary buttons, and links. All interactive states are derived from this single accent hue.

--accent

--accent-hover

--accent-bg
Accent tint background. Active nav item fill, selected rows.
--accent-subtle
Very faint accent tint. Hover backgrounds on interactive elements.
